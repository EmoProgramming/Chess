# Chess

This project is an extension of my first *Zápočtový program*, for which I created a chess application in C++ with the board displayed in the terminal.

I decided to take the project further and make it more user-friendly by displaying the chessboard on a webpage. The application is still written in C++, while **WebAssembly (WASM)** allows me to run the C++ code in the browser and connect it with **JavaScript**, which handles the web interface.

**Live demo:** [Chess](https://www.ms.mff.cuni.cz/~granskye/chess/)
